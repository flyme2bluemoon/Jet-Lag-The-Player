# Context map

Use the context that owns the domain language being named or changed.

- [Shared product context](CONTEXT.md): seasons, episodes, competitors, playback-synchronized game state, dashboards, and the distinction between dashboard cards and game cards.
- [Season 4 context](app/src/seasons/season-4/CONTEXT.md): Battle 4 America challenge cards, hands, claimed states, battles, power-up tokens, and travel budgets.
- [Season 9 context](app/src/seasons/season-9/CONTEXT.md): Hide + Seek runs, roles, questions, coins, curse dice, and curse cards.
- [Season 18 context](app/src/seasons/season-18/CONTEXT.md): Stateside Scramble states, public and private cards, claims, scoring, tiebreaks, and travel budgets.

The shared product context applies inside every season context. A season context owns the game-specific meaning when ordinary language would be ambiguous.
